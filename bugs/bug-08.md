# BUG-08: API буруу JSON өгөгдөлд 200 OK статус буцааж байна

**Олдсон цаг:** 2026-10-16, 17:40
**Тестийн объект:** Уншлагын жагсаалт v2.0
**Орчин:** Windows, PowerShell, Node.js
**Аялал:** Saboteur
**Ноцтой байдал (Severity):** Major
**Төлөв (Status):** Open

## 1. Алдааны тайлбар

Уншлагын жагсаалт аппликейшний
POST /api/books API endpoint руу
JSON форматад нийцээгүй өгөгдөл
илгээхэд сервер хүсэлтийг
амжилттай гэж хүлээн авч байна.

Лабораторийн спецификацийн дагуу
буруу JSON өгөгдөлтэй POST хүсэлтэд
HTTP 400 Bad Request статус
буцаах ёстой.

Гэвч invalid-json гэсэн буруу
өгөгдлийг илгээхэд сервер
HTTP 200 OK статус буцаасан.

## 2. Дахин гаргах алхмууд

**Урьдчилсан нөхцөл:**
Node.js серверийг шинээр ажиллуулсан.
Анхны 3 ном өгөгдлийн жагсаалтад байна.

1. VS Code-ийн Terminal дээр
   `node app/app.js` командыг ажиллуулна.
2. Шинэ PowerShell Terminal нээнэ.
3. Дараах командыг ажиллуулна:

   curl.exe -i -X POST "http://localhost:3000/api/books" -H "Content-Type: application/json" --data-binary "invalid-json"

4. HTTP статус болон серверийн
   хариуг шалгана.

## 3. Хүлээгдсэн үр дүн

JSON форматад нийцээгүй хүсэлтийг
сервер хүлээн авахаас татгалзаж,
HTTP 400 Bad Request статус
буцаах ёстой.

Хүсэлтийг амжилттай боловсруулсан
мэт хариу өгөх ёсгүй.

## 4. Бодит үр дүн

Сервер дараах хариуг буцаасан:

HTTP/1.1 200 OK
Content-Type: application/json

{"result":"OK"}

Ингэснээр буруу JSON өгөгдөлд
зөв статус буцаах шаардлага
биелээгүй байна.

## 5. Ноцтой байдлын үндэслэл

Major — API нь буруу оролтын өгөгдлийг
зөв таньж, HTTP алдааны статус
буцаахгүй байгаа нь клиент систем
болон серверийн харилцаанд
найдваргүй байдал үүсгэнэ.

Клиент аппликейшн буруу хүсэлтийг
амжилттай гүйцэтгэсэн гэж
ойлгох эрсдэлтэй.

## 6. Нотолгоо

API хүсэлтийн HTTP статус,
header болон response body-г
дараах файлд хадгалсан.
