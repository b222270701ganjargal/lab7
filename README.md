# Лаборатори №7 — Exploratory Testing (SBTM)

**Хичээл:** Программ хангамжийн чанарын баталгаа ба тест (F.CSA313)  
**Оюутны код:** B222270701
**Гүйцэтгэсэн:** Г.Ганжаргал  
**Огноо:** 2026-10-16  
**Тестийн хугацаа:** 17:01–18:01 (60 минут)
**Браузер:** Google Chrome
**Браузерийн хувилбар:** 155.0.8059.85 (64-bit)
**Node.js хувилбар:** v20.17.0

## 1. Зорилго

Уншлагын жагсаалт v2.0 веб аппликейшний
үндсэн үйлдэл, өгөгдлийн баталгаажуулалт,
хайлтын ажиллагаа, хэрэглэгчийн интерфейс
болон API-ийн ажиллагааг exploratory testing
аргаар шалгаж, согогуудыг илрүүлэх.

## 2. Ашигласан аргачлал

Session-Based Test Management (SBTM)
аргачлалын дагуу 60 минутын тестийн
session зохион байгуулсан.

Дараах exploratory testing аяллуудыг ашиглав:

- Couch Potato — Ердийн болон буруу
  оролтын өгөгдлийг шалгах.
- Saboteur — API руу буруу өгөгдөл
  илгээж, серверийн хариуг шалгах.
- Supermodel — Интерфейсийн харагдах
  байдал, байрлал, мэдээллийн нийцлийг шалгах.

## 3. Тестийн орчин

- Үйлдлийн систем: Windows
- Веб хөтөч: Google Chrome
- Runtime: Node.js
- Редактор: Visual Studio Code
- Хаяг: http://localhost:3000

### 7.2 Аялал тус бүрээр илрүүлсэн согогууд

**Couch Potato аялал**

Ердийн хэрэглээ, буруу оролт болон
өгөгдлийн баталгаажуулалтыг шалгав.

- BUG-04: Гарчиггүй ном нэмэгдэж байна.
- BUG-05: Номын оны зөвшөөрөгдөх
  хязгаарыг шалгахгүй байна.
- BUG-06: Давхардсан ном нэмэгдэж байна.
- BUG-07: Хайлт том, жижиг үсэг ялгаж байна.

**Saboteur аялал**

Серверийн алдаа боловсруулах ажиллагааг
буруу API хүсэлтээр шалгав.

- BUG-08: Буруу JSON өгөгдөлд
  HTTP 200 OK буцааж байна.

**Supermodel аялал**

Интерфейсийн харагдах байдал,
мэдээллийн нийцэл болон хэрэглэгчид
үзүүлэх мессежийг шалгав.

- BUG-01: Номын нийт тоолуур буруу.
- BUG-02: Устгах товч ногоон өнгөтэй.
- BUG-03: Номын он буруу форматтай.
- BUG-09: Ном устгасны дараа
  амжилтын мессеж шинэчлэгдэхгүй.
- BUG-10: Урт гарчиг хүснэгтийн
  байрлалыг алдагдуулж байна.

### 7.3 Charter-аас гадуур хийсэн шалгалт

Анхны Charter-д ном нэмэх, хайх, устгах,
өгөгдлийн баталгаажуулалт, интерфейс
болон API-ийн ажиллагааг шалгахаар
төлөвлөсөн.

Туршилтын явцад дараах нэмэлт
нөхцөлүүдийг нарийвчлан судлав.

- 2100 оныг зөвшөөрч байгаа эсэх болон
  2101 оныг хориглож байгаа эсэхийг
  тус тус шалгасан.
- Зохиолчийн бүтэн нэрээр хайлт хийж,
  "Clean Code" ном зөв гарсныг баталсан.
- Ном устгасны дараах мессежийн төлөвийг
  шалгаж, BUG-09-ийг илрүүлсэн.
- Маш урт гарчиг оруулж, хүснэгтийн
  байрлал болон хэвтээ гүйлгэлтийг шалгасан.

Эдгээр нь Charter-ийн үндсэн зорилготой
холбоотой боловч анх тусгайлан
тодорхойлоогүй нэмэлт туршилтууд байв.

### 7.4 Playwright болон хүний нүдээр шалгах нь

**Playwright автомат тестэд тохиромжтой:**

- Ном нэмэхэд заавал бөглөх талбарын
  баталгаажуулалтыг шалгах (BUG-04).
- 999, 2100, 2101 зэрэг хязгаарын
  утгуудыг шалгах (BUG-05).
- Давхардсан ном нэмэгдэх эсэхийг
  шалгах (BUG-06).
- Том, жижиг үсэг ялгахгүй хайлтыг
  шалгах (BUG-07).
- API-ийн HTTP статус болон response
  body-г шалгах (BUG-08).
- Ном нэмэх, устгах үеийн тоолуур,
  мессежийн өөрчлөлтийг шалгах
  (BUG-01, BUG-09).

**Хүний нүдээр шалгахад тохиромжтой:**

- Устгах товчны өнгө, харагдах байдал
  ойлгомжтой эсэх (BUG-02).
- Номын он хэрэглэгчид уншихад
  тохиромжтой форматтай эсэх (BUG-03).
- Урт гарчиг оруулахад хүснэгтийн
  байрлал, уншихад тохиромжтой
  байдал алдагдах эсэх (BUG-10).

Playwright нь давтагдах боломжтой,
тодорхой хүлээгдсэн үр дүнтэй шалгалтыг
автоматжуулахад тохиромжтой.

Харин хүний нүдээр шалгах нь
интерфейсийн ойлгомжтой байдал,
харагдах байдал болон хэрэглэгчийн
туршлагыг үнэлэхэд илүү тохиромжтой.

### 7.5 Эцсийн дүгнэлт

Тестийн явцад өгөгдлийн баталгаажуулалт,
давхардлын шалгалт, хайлт, API-ийн
алдааны боловсруулалт болон интерфейсийн
согогууд илэрсэн.

Хамгийн түрүүнд BUG-04, BUG-05,
BUG-06, BUG-07 болон BUG-08-ыг
засварлах шаардлагатай гэж үзэв.

Эдгээр нь өгөгдлийн чанар болон үндсэн
функцийн найдвартай байдалд нөлөөлж байна.

Цаашид Playwright автомат тест болон
хүний нүдээр хийх exploratory тестийг

алдааг дахин илрүүлэх, программын чанарыг
сайжруулах боломжтой.
