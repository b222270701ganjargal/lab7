# Лаборатори №7 — Exploratory Testing (SBTM)

**Хичээл:** Программ хангамжийн чанарын баталгаа ба тест (F.CSA313)  
**Гүйцэтгэсэн:** Г.Ганжаргал  
**Огноо:** 2026-10-16  
**Тестийн хугацаа:** 17:01–18:01 (60 минут)

## 1. Зорилго

Уншлагын жагсаалт v2.0 веб аппликейшний
үндсэн үйлдэл, өгөгдлийн баталгаажуулалт,
хайлтын ажиллагаа, хэрэглэгчийн интерфейс
болон API-ийн ажиллагааг exploratory testing
аргаар шалгаж, согогуудыг илрүүлэх.

## 2. Ашигласан аргачлал

Session-Based Test Management (SBTM)
аргачлалын дагуу 60 минутын тестийн
session зохион байгуулсан.

Дараах exploratory testing аяллуудыг ашиглав:

- Couch Potato — Ердийн болон буруу
  оролтын өгөгдлийг шалгах.
- Saboteur — API руу буруу өгөгдөл
  илгээж, серверийн хариуг шалгах.
- Supermodel — Интерфейсийн харагдах
  байдал, байрлал, мэдээллийн нийцлийг шалгах.

## 3. Тестийн орчин

- Үйлдлийн систем: Windows
- Веб хөтөч: Google Chrome
- Runtime: Node.js
- Редактор: Visual Studio Code
- Хаяг: http://localhost:3000

1. Төслийн үндсэн хавтсанд Terminal нээнэ.
2. Дараах командыг ажиллуулна:

   node app/app.js

3. Веб хөтөч дээр дараах хаягаар орно:

   http://localhost:3000

## 7. Debrief — Тестийн дүгнэлт

60 минутын exploratory testing session-ийн
хүрээнд Уншлагын жагсаалт v2.0
аппликейшний үндсэн ажиллагааг шалгав.
Тестийн явцад нийт 10 ялгаатай согог
илрүүлж, тэдгээрийг баримтжуулсан.
Хамгийн ноцтой асуудлууд нь өгөгдлийн
баталгаажуулалт болон бизнес дүрмийн
шалгалттай холбоотой байв.
Хоосон гарчиг, зөвшөөрөгдөх хүрээнээс
гадуурх он болон давхардсан ном
нэмэгдэх боломжтой байгааг тогтоов.
Мөн хайлт том, жижиг үсэг ялгаж
байгаагаас хэрэглэгч шаардлагатай
номоо олоход хүндрэл үүсэж байна.
API тестээр буруу JSON өгөгдөлд
HTTP 200 OK буцааж байгааг илрүүлэв.
Интерфейсийн шалгалтаар буруу өнгө,
оны формат, үйлдлийн мессеж болон
урт текстийн байрлалтай холбоотой
алдаануудыг илрүүлсэн.
Харин зохиолчийн нэрээр хайх болон
2100 онтой ном нэмэх туршилтууд
амжилттай болсон.
Цаашид өгөгдлийн баталгаажуулалт,
API-ийн алдааны боловсруулалт болон
интерфейсийн тогтвортой байдлыг
сайжруулах шаардлагатай гэж дүгнэв.
